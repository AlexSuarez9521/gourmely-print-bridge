Record the failing assertion and the later passing result for each rule; do not invent hardware proof. The native RDD candidate-consent contract still governs each review.
S4. Verify against the read-only production web implementation; do not advertise support before the durability condition is met.

S7. Communication: "Avísame con herdr agent prompt gourmelyhub '[Bridge-Codex] …' al cerrar cada unidad." The earlier standing rule also requires the same one-line notification when writing files.
S8. Fingerprint dependency: "usa el crate estándar de RustCrypto (sha2), versión fija en Cargo.toml, sin features extra" and "Si ya hay un crate de hash en el árbol que sirva, no agregues uno nuevo." Explain the payload fingerprint, dependency-tree evidence, and direct-dependency rationale in the dependency commit.
